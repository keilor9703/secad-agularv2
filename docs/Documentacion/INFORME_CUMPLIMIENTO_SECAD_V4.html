⚠️ Brechas Críticas — Riesgo Alto para la Entrega

  • Arquitectura de microservicios + Docker/Kubernetes: La ficha exige microservicios contenerizados. El proyecto actual es monolítico (.NET 8 + Angular SPA). Es la desviación arquitectónica más importante.
  • Vault para cifrado de credenciales: Las credenciales de BD de tenants deben cifrarse con HashiCorp Vault y rotarse cada 90 días. No implementado.
  • Modo Offline/Degradado: Requerido para zonas PDET (Vaupés, Amazonas, etc.). No existe lógica de resiliencia de 3 niveles.
  • Módulo Cámaras (VMS), Análisis Predictivo, Chatbot 123, Alarmas Comunitarias, Calidad del Servicio: 5 módulos completos NO iniciados.
  • ETL/Data Warehouse Nacional: Apache Airflow + DW centralizado + anonimización. No implementado.
  • NG911/NG112/NENA i3: Estándares internacionales de interoperabilidad. No implementados.
  • PWA (Progressive Web App): Carga offline de interfaz requerida. No configurado.
  • Pruebas: No se encontraron tests unitarios, de integración ni de rendimiento en el proyecto.
