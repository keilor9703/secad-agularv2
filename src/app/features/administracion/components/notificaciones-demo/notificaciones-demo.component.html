Use toast para respuestas breves y no bloqueantes. Use SweetAlert2 cuando el usuario deba reconocer o confirmar una decisión.

Toast: resultado inmediato sin detener la tarea.
Alerta: información que debe ser reconocida.
Confirmación: antes de cambios sensibles o permanentes.
