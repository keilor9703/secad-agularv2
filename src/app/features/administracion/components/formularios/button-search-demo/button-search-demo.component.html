API principal de ui-search-input

Propiedad Valores Uso
buttonLayout attached | detached Une o separa el botón del campo.
buttonGap number | string Separación cuando el botón está detached.
buttonText string Texto visible y nombre accesible de búsqueda.
buttonVariant Tonos de ui-button Aplica el color semántico compartido.
buttonAppearance solid | soft | outline | ghost Define la intensidad visual.
buttonIconColor Color CSS Personaliza únicamente el icono.
buttonBackgroundColor Color CSS Sobrescribe el fondo de una instancia.
buttonTextColor / buttonBorderColor Color CSS Controla texto y borde independientemente.
hideButtonTextOnMobile boolean Oculta el texto visual conservando aria-label.

API principal de ui-button

Propiedad Valores Uso
variant primary, secondary, info, success… Selecciona el tono semántico.
appearance solid | soft | outline | ghost Selecciona la apariencia del tono.
size sm | md | lg Escala responsive del botón.
iconPosition start | end Posición del icono respecto al texto.
loading / disabled boolean Estados no interactivos accesibles.
backgroundColor Color CSS Sobrescribe el fondo de una instancia.
textColor / iconColor Color CSS Ajusta texto e icono independientemente.
