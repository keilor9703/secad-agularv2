API de los encabezados

Componente Entrada Tipo Predeterminado Uso
ui-page-header title string Requerido Título principal del módulo.
ui-page-header minimized model<boolean> false Estado bidireccional de minimización.
ui-page-header minimizable boolean true Muestra u oculta el control menos/expandir.
ui-page-header page-header-actions slot Vacío Badges y acciones del módulo.
ui-chip appearance outline | glass outline Indicador blanco o integrado en cabeceras oscuras.
ui-chip value string | number null Valor numérico destacado antes de la etiqueta.
ui-panel-header appearance institutional | soft institutional Fondo oscuro o cabecera clara.
ui-panel-header icon string Vacío El icono es completamente opcional.
ui-panel-header panel-header-actions slot Vacío Indicadores del panel.
ui-section-header eyebrow string Vacío Categoría superior.
ui-section-header compact boolean true Controla la altura de la sección.
ui-section-header appearance boxed | divider boxed Selecciona cabecera con icono en caja o separador liviano.
ui-section-header showAccent boolean true Muestra u oculta la línea lateral de divider.
ui-section-header accentWidth number 4 Grosor entre 0 y 8 px de la línea lateral.
ui-expansion-panel expanded model<boolean> false Estado reactivo; admite enlace bidireccional con una signal.
ui-expansion-panel appearance card | divider divider Define la apariencia de la cabecera desplegable.
ui-expansion-panel indicator plus-minus | chevron | custom plus-minus Selecciona el indicador situado al extremo derecho.
ui-expansion-panel density compact | comfortable compact Ajusta la altura y el espaciado interno.
ui-expansion-panel disabled boolean false Bloquea la interacción conservando el contenido.
ui-expansion-panel showAccent boolean true Muestra u oculta la línea azul en la apariencia divider.
ui-expansion-panel accentWidth number 4 Define un grosor seguro entre 0 y 8 px.
ui-expansion-panel accentScope header | panel panel Aplica la línea solo a la cabecera o a toda la altura del panel.
ui-expansion-panel frame panel | header | none panel Controla el marco neutro sin modificar la línea azul.
ui-expansion-panel contentRowGap number 18 Separación vertical heredada por los formularios proyectados.
ui-expansion-panel contentColumnGap number 14 Separación entre columnas; admite valores de 0 a 48 px.
Todos headingId string Automático Referencia accesible del título.
